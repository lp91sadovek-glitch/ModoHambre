ℹ️ ¿De dónde salen estos pedidos?

Los clientes piden desde la web y cada pedido queda guardado en la base de datos del local. Esta pantalla se actualiza sola cada 4 segundos y se puede abrir desde cualquier computadora o celular con la clave.

Sacar un pedido de la pantalla no lo borra: sigue en el registro de pedidos, donde también se puede bajar una copia a la computadora.

Con el botón Local abierto / cerrado decidís si la web acepta pedidos. Cerralo cuando termine el horario.

Esta pantalla pide la clave del local porque muestra el nombre, el teléfono y la dirección de los clientes.
